# HDSF review

The Health Data Safety Framework turns EU rules for digital health (GDPR, MDR and IVDR, EHDS, AI Act, CRA, NIS2,
Data Act, Product Liability Directive) into checkable rules. This skill runs its scanner and helps the team act on
the report. HDSF is not legal or regulatory advice; say so when a decision needs an expert.

## Steps

1. **Find or make the manifest.** Look for `hdsf.yaml` at the product's root. If there is none, copy
   `templates/hdsf.yaml` and fill it with the team, asking only what the code and documents cannot tell you.
   Start with the intended purpose, in one or two full sentences.
2. **Ask the device question early.** Read `framework/rules.yaml` rules CORE-QUA-01 to CORE-QUA-04. Walk through the
   MDCG 2019-11 rev. 1 steps with the team. Never decide qualification for them; record their reasoning and point to
   a regulatory expert when it is unclear. "Undecided" blocks launch.
3. **Run the scanner** from this skill folder:
   ```bash
   python3 scripts/scan.py --repo <product path> --level 1 --out-dir hdsf-report --format md,json,sarif
   ```
   Use `--description-only` when there is no code. Use `--level 2` to plan for EHDS, CRA and AI Act dates.
   Add `--docs <folder>` to review the privacy notice and the store and onboarding texts. Add `--export html,docx` (and `pdf` when
   Chrome is installed) for a dashboard and a Word report.
4. **Read the report with the team.** Fix BLOCK items first, then REVIEW, then WARN. For each HUMAN item, ask
   for the evidence and note where it lives. Explain each rule with its "why" and its sources; never invent a
   source or a date.
5. **Draft missing documents** when asked: qualification record, DPIA outline, AI inventory, incident plan. Mark
   drafts as drafts for the team to check.
6. **Children.** If users include children, also apply the Child-Safe EdTech Framework (CSEF,
   https://csef.kendirstudios.pt) and link its report in `children.csef_report`.

## Files

- `scripts/scan.py`, `scripts/checks.py`, `scripts/docreview.py`, `scripts/export.py`, `scripts/sfe/`: scanner, manifest checks, document review, exports, engine
- `framework/rules.yaml`, `framework/sources.yaml`, `framework/framework.yaml`: rules, sources, configuration
- `templates/hdsf.yaml`: manifest template

These are copies generated by the HDSF repository's `tooling/build.py`; update them from there.
