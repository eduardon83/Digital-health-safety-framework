    Run the checks

    You get one report with: the rules that apply and what the description shows; a review of your documents (privacy notice against GDPR/RGPD Art. 13 and 14, medical claims, safety and AI wording, plain language, risky wording); EU recommendations that apply (level 2) and design recommendations from research (level 3).

      How this page handles your files

      The HDSF tools are Python programs. This page runs them inside your browser with Pyodide, downloaded from the jsDelivr CDN the first time. Your files are read by the browser and never sent anywhere: no server, no account, no analytics. Close the tab and everything is gone; download what you want to keep. To save the report as PDF, open it and use "Print or save as PDF".

      Organisations that block CDNs can host Pyodide themselves and open this page with ?pyodide=https://their-host/pyodide/. Developers get the same results, plus the code checks, with tooling/workbench.py and tooling/scan.py.

      The checks find signs. A person confirms them. This is not legal or regulatory advice.
