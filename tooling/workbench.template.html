      How this page handles your files

      The HDSF tools are Python programs. This page runs them inside your browser with Pyodide, downloaded from the jsDelivr CDN the first time. Your files are read by the browser and there is no data sent or stored anywhere: no server, no account, no analytics. Keep in mind that if you close the tab, all information will disappear, so download what you want to keep. To save the report as PDF, open it and use "Print or save as PDF".

      Organisations that block CDNs can host Pyodide themselves and open this page with ?pyodide=https://their-host/pyodide/. Developers get the same results, plus the code checks, with tooling/workbench.py and tooling/scan.py.

      Consider that this tool will find signs, but you will need someone to confirm them.
